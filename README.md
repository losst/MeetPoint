## Project Overview

MeetPoint is a full-stack scheduling and booking platform designed to simplify appointment coordination between students and professors. The system allows users to create and manage availability, book and cancel appointments, receive status updates, and coordinate group meetings through a centralized interface.

The project was developed as a team-based web application with a focus on database-driven functionality, role-based user interactions, and responsive frontend design.
